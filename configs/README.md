# configs

По умолчанию используется `learned-router-r1-submit.json`: оценки расхода,
вероятности успеха и лимиты для 16 сочетаний типа задачи и модели.

`learned-router-v2.json` — исходные зафиксированные таблицы.
`learned-router-r1-submit-review.json` — запись проверки их совместимости
с исправлениями исполнения и сдачи ответа. Все три файла нужны при запуске.
Пути к исследовательским тестам и Git-коммитам внутри записи относятся к
истории разработки; для запуска и `harness.bundle check` эти материалы не нужны.

Оценки исполняются обычным Python без ML-библиотек и загрузки моделей.
Не редактируйте хеши вручную: они связывают таблицы с конкретным кодом и промптами.
