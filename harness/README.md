# harness

`core.py` загружает публичные данные задачи и собирает промпт.
`routing.py` формирует планы для четырёх моделей, `deployed.py` читает
зафиксированные оценки, `planning.py` выбирает задачи в пределах бюджета.
`runner.py` выполняет выбранный план и пересчитывает остаток.

`agent.py` исполняет JSON-действия модели. `submission.py` проверяет сдачу ответа
и неизменность публичных тестов. `provider.py` обращается к API через openJiuwen,
`accounting.py` учитывает физические запросы, `rate_limit.py` ограничивает частоту.

`bundle.py` проверяет соответствие исходников и конфигурации.
Модули `*_report.py`, `statistics.py` и `replay.py` нужны для анализа журналов.
`sufficiency*.py` содержат экспериментальную проверку достаточности данных;
в стандартном запуске она отключена.

Настройки запуска и формат задач описаны в [корневом README](../README.md).
